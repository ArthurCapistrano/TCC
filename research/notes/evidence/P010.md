## Metrics / Evaluation

- Detection Accuracy: `(TP + TN) / (TP + TN + FP + FN)`.
- False Positive Rate: `FP / (FP + TN)`.

## Main Results

Principais Resultados:
- A Tabela I registra para Deequ: Detection Accuracy de 84,2%, FPR de 12,5%, RSR de 65,4% e latência de 187 ms por 10 mil linhas.
- Para Great Expectations: Detection Accuracy de 86,5%, FPR de 10,2%, RSR de 71,1% e latência de 175 ms.
- Para o sistema proposto: Detection Accuracy de 94,6%, FPR de 4,7%, RSR de 89,2% e latência de 122 ms.
- Os autores declaram que a Schema Drift Detection Accuracy alcançou 97,1% após uma simulação de 12 horas.
- O RSR do agente de reinforcement learning teria aumentado de 68% para 89,2% ao longo de 100 episódios.
- Os autores declaram redução de 30% no tempo para detectar anomalias e aumento de aproximadamente 8% na acurácia em comparação com Great Expectations e Deequ.
- OpenRefine é declarado como baseline, mas não recebe resultados na tabela ou nas figuras.
- Os valores são resultados declarados pelos autores; a fonte não fornece dados ou configuração suficientes para auditoria ou reprodução independente.
